## ✨ Fitur Utama

### 🎥 Streaming & Konten
- **Kualitas HD** - Streaming dengan kualitas hingga 1080p
- **Subtitle Indonesia** - Terjemahan akurat dan berkualitas
- **Koleksi Lengkap** - Anime terbaru dan klasik
- **Update Rutin** - Episode baru ditambahkan secara berkala

### 🔍 Penelusuran
- **Pencarian Cepat** - Temukan anime dengan mudah
- **Kategori Terorganisir** - Popular, Trending, Terbaru
- **Filter Advanced** - Berdasarkan genre, tahun, status
- **Rekomendasi Personal** - Sesuai selera menontonmu

### 👤 Pengalaman Pengguna
- **Bookmark Favorite** - Simpan anime yang ingin ditonton
- **Riwayat Nonton** - Lanjutkan dari episode terakhir
- **Dark Mode** - Tema gelap untuk kenyamanan mata
- **User-Friendly** - Interface intuitif dan mudah digunakan

## 🚀 Memulai

### Prasyarat
- Flutter SDK 3.0 atau lebih tinggi
- Dart 2.17 atau lebih tinggi
- Android Studio / VS Code dengan ekstensi Flutter

### Langkah Instalasi

```bash
# Clone repository
git clone https://github.com/lavenderpoet607/ResoNime.git

# Masuk ke direktori project
cd ResoNime

# Install dependencies
flutter pub get

# Jalankan aplikasi
flutter run
